# The Farmers Market at Mainstreet Acres

Vendor recruitment site for Mainstreet Acres Farmers Market (Redland, Miami). Plain HTML, CSS, and JS. No build step.

## Pages
- `index.html`: home (hero, vendor categories, why join, market details + map, CTA)
- `vendors.html`: how it works, who we welcome, requirements, FAQ
- `apply.html`: vendor registration form + contact card

## Before launch
- **Hero photo** is a placeholder from Unsplash. Replace it with a real market photo in `assets/`.
- **Logos**: `assets/logo.webp` is the main logo. Swap in the final files when they arrive.
- **Form** posts to FormSubmit (`formsubmit.co`) and emails stephanie@cmgproducts.net. The first submission sends an activation email to that inbox. Click the link once and later submissions arrive normally.

## Hosting
Works on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
